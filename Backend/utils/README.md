# Utils

Utilities contain reusable backend helpers that are shared across controllers, middleware, and startup code.

## Current Files

- `apiError.js` defines a reusable API error structure.
- `apiResponse.js` defines a reusable API response structure.
- `asyncHandler.js` wraps async route logic.
- `cloudinary.js` configures or performs Cloudinary upload work.
- `connectDB.js` handles MongoDB connection setup.
- `notify.js` contains notification helper logic.
